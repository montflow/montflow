# Memory module

Schema-free verification for one `MEMORY.md` — the per-task working
notes file. Checks that it is non-empty, has a `# Memory` title, and
carries the template's sections.

## Belongs here

- `MEMORY_SECTIONS`, `verifyMemoryFile`

## Does not belong here

- Parsing the `## Review Loop Counter` value — the executor owns that
- Any prose quality judgement — review concern, not mechanical
