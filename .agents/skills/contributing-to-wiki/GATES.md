# Gates

Validate the wiki work product — not these skill files.

## Phase 1: Prose Style (i-have-adhd)

- [ ] First line of each new/edited page states what the reader gets or does — no "This document describes..."
- [ ] Procedures are numbered lists with one bounded action per step
- [ ] No list exceeds 5 items without splitting into categories
- [ ] No recap or pleasantry closers on any page

## Phase 2: Diagrams

- [ ] Every flow with 3+ steps, component relationship, state machine, or event sequence has a Mermaid diagram
- [ ] No diagram re-draws a flow already owned by another page — it links instead
- [ ] All Mermaid blocks use fenced ` ```mermaid ` syntax and render without parse errors

## Phase 3: Hyperlink Graph

- [ ] Every relative link resolves to an existing file
- [ ] Every new page is linked from wiki/index.md
- [ ] Each page links to at least 2 related pages
- [ ] First mention of any concept that has its own page is hyperlinked
