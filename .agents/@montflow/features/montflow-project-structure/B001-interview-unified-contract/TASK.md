# Task B001: Interview the user on the unified contract

## Type: planning

## Description

Present the Phase A rule matrix, conflicts, gaps, and candidate shape to the
user and settle what the project-structure rules should really be. This is a
user-decision task: use the interview to capture their choices, not to decide
for them.

## Requirements

- Ask the user which rules stay, which change, and which are dropped, reacting to each conflict and gap from A005.
- Settle scope: which skills the unified entry point depends on, and what is explicitly out of scope.
- Settle naming: the unified skill name, any group/module names, and the naming vocabulary the rules use.
- Record every decision with the user's rationale; leave genuinely deferred questions explicitly open.
- No files outside `.agents/@montflow/features/` are modified.
